# Project conventions

## Commits

Always write commit messages in **English**.

Commit messages must be **concise, a single line**, prefixed with a gitmoji (e.g. `⚡ optimise kill chain page`). No body, no extra paragraphs.

**Never** add a `Co-Authored-By` trailer or any mention of Claude / AI co-authorship in commit messages or PR descriptions.

When the user asks for a commit during a conversation, only stage and commit the files that were modified during that conversation — do not include pre-existing unstaged changes unrelated to the current work.
